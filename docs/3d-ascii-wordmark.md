# 3D Extruded ASCII Wordmark & Terminal Profile Art

This directory contains the automation pipeline and rendering engine for the animated terminal SVGs featured on [@goyalrajat4322-hash](https://github.com/goyalrajat4322-hash)'s GitHub profile README.

---

## 🎨 Overview of Components

1. **`wordmark.svg`**: Extruded 3D ASCII voxel shell generated by `scripts/make_wordmark_svg.py` with smooth rocking SMIL animation.
2. **`info-card.svg`**: Neofetch-style terminal info card generated by `scripts/make_info_card.py` featuring academic, ML, and technical background.
3. **`rajat-ascii.svg`**: Self-typing ASCII avatar generated by `scripts/make_ascii_svg.py`.
4. **`contrib-heatmap.svg`**: Live 53-week animated contribution calendar generated by `scripts/fetch_contributions.py` + `scripts/render_heatmap_svg.py` and auto-refreshed daily by GitHub Actions.

---

## 🚀 Scripts

### 1. Extruded 3D Wordmark (`scripts/make_wordmark_svg.py`)
Renders `"RAJAT"` in 3D perspective with Lambert shading:
```bash
python scripts/make_wordmark_svg.py --mode rock
```
Options:
- `--mode [rock|spin|once|static]`
- `--dur <seconds>`
- `--frames <count>`

### 2. Neofetch Info Card (`scripts/make_info_card.py`)
Generates terminal status card with line fade-ins:
```bash
python scripts/make_info_card.py
```

### 3. Contribution Heatmap (`scripts/fetch_contributions.py` & `scripts/render_heatmap_svg.py`)
Scrapes unauthenticated public contribution calendar and renders animated SVG:
```bash
python scripts/fetch_contributions.py
python scripts/render_heatmap_svg.py
```

### 4. Photo to ASCII Conversion (`scripts/prep_photo.py` & `scripts/make_ascii_svg.py`)
Prepares photo with CLAHE local contrast and generates row-wiping ASCII SVG:
```bash
python scripts/prep_photo.py source-photo.jpg
python scripts/make_ascii_svg.py source-prepped.png rajat-ascii.svg
```

---

## ⚡ GitHub Actions Automation

`.github/workflows/update-profile-art.yml` executes daily at `06:17 UTC`:
- Checks out repository
- Scrapes latest public contribution data
- Re-renders `contrib-heatmap.svg`
- Auto-commits updated SVGs using `git-auto-commit-action` with `[skip ci]`.
